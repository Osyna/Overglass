Enter your access token

This page controls your TV, so it asks for a token the first time. It is the server_token from the Overglass config, or the one passed to wof serve --token.

Where do I find my token?
  1. On the computer that runs wof, open a terminal and run wof config show. The token is the server_token line.
  2. Or start the server with wof serve --generate-token. It prints a new token once, as it starts.
  3. Running on the TV itself? The token is printed in /tmp/webos-foundry-tv-server.log on the TV the first time it starts.

Turn login off?

With login off, this page no longer asks for a token, on any network it can be reached from.

  • Anyone who can reach this address can turn the TV on and off, change the volume and open apps.
  • They can also install or remove apps, and see the screen through Screenshot and Live view.
  • Fine on a home network you trust. Not fine on shared or public Wi-Fi.
